# 📦 商品管理系統 (Product Management System)

本文件說明 YoGo 芽菜工坊的商品目錄管理、庫存機制與上架規範。

## 🛠️ 管理方式

商品資訊儲存於 **Firebase Firestore (`products` collection)**。

- **初始化**: 系統啟動時會透過 `apps/backend/src/data/seeder.ts` 自動注入初始商品。
- **更新**: 管理員可於 Firebase Console 或透過後端 `/api/admin/products` (待實作) 更新庫存與售價。

## 📋 商品清單與類別 (Product Catalog)

詳細商品定義請參考 `packages/shared/src/index.ts` 中的 `INITIAL_PRODUCTS`。

### 核心分類:

1. **kit (種植套組)**: 入門盒、五件套等。
2. **seeds (種子零售)**: 青花椰、紫高麗、苜蓿等。
3. **fresh (新鮮芽菜)**: 白玉花生芽、紫高麗菜芽等 (需低溫配送)。
4. **peanut (好事花生)**: 花生芽粉、洛神飲包等周邊。
5. **drinks (即飲系列)**: 花生芽咖啡等。

## 🔍 商品屬性說明

| 屬性       | 說明                           |
| :--------- | :----------------------------- |
| `id`       | 唯一數字編號                   |
| `name`     | 商品名稱                       |
| `price`    | 銷售價格 (NT$)                 |
| `cold`     | 是否為冷藏商品 (影響配送分組)  |
| `stock`    | 當前庫存量 (為 0 時顯示已售完) |
| `spec`     | 包裝規格 (例如: 100g/盒)       |
| `features` | 商品特色描述 (用於詳情頁顯示)  |

## 📈 庫存管理規範

- **低庫存警示**: 當 `stock < 5` 時，系統建議於後端標記為「熱銷補貨中」。
- **冷鏈限制**: 標記為 `cold: true` 的商品在結帳時會自動歸類至「冷藏保鮮區」。
